Инженерные задачи курсового проекта

1 Проектирование высоконагруженного RESTful API на платформе ASP.NET Core 9

3 Интеграция с DaData API для предиктивного поиска адресов и городов РФ
4 Автоматизация кухни, партионного учета StockLog и финансовой модели COGS

Разработанный программный комплекс

Создан замкнутый цикл доставки Dark Kitchen: витрина с кастомизатором блюд, DaData гео-поиск, онлайн-трекер кухни, рабочее место оператора, журнал сырья StockLog, курьерская логистика и расчет рентабельности COGS.

Перспективы развития сервиса

Подключение онлайн-эквайринга Системы быстрых платежей (СБП по динамическому QR), выпуск кросс-платформенного мобильного PWA-приложения и масштабирование сети на соседние районы Саратовской области.
